# Domain docs

This repository uses a single domain context.

Before exploring or changing a domain area:

1. Read the root `CONTEXT.md` and use its canonical vocabulary.
2. Read relevant decisions under `docs/adr/` when that directory exists.
3. Surface conflicts with an existing ADR instead of silently overriding it.

Missing domain documents are created lazily by the domain-modeling flow when a term or durable decision is resolved.
